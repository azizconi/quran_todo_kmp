# Словарь приложения (U26)

Одно слово на одно понятие, на пяти языках. Тексты лежат в `composeApp/src/androidMain/kotlin/tj/app/quran_todo/ui/i18n/*.kt`. Правила проверяются тестом `GlossaryCopyTest`.

## Обращение

Русский: только «вы» («Послушайте», «Прочитайте», «Вспомните», «Отметьте»). Короткие метки вкладок и кнопок — инфинитив («Слушать», «Читать», «Вспомнить»). Таджикский: «Шумо» (-ед). Узбекский: «Siz» (-ing, -ingiz). Турецкий: «siz» (-in, -ın, -iniz). Привычные кнопки действия в турецком («Kaydet», «Sil», «Paylaş») остаются голым повелительным: так принято в интерфейсах и к человеку это не обращение. Английский без изменений.

## Решения по ходу работы

- «Повтор» (звук): плеер, ряд действий аята, настройки звука, эхо. «Повторение» (выученное): круг, итоги, напоминания. Кнопка «Повторить попытку» после ошибки теперь «Ещё раз» (в EN осталось «Retry»).
- «Прочитайте по памяти» вместо «Повторите по памяти»: слово «повторить» не мешаем со звуком.
- Тест строится по пройденному (covered), не по выученному; подпись «по пройденному».
- План закончен, когда все суры плана пройдены («пройдены», не «выучены»).
- Статус суры в листе: «Учу» / «Выучено». Бывшая кнопка «Знаю наизусть» теперь «Выучено» (по смыслу то же состояние).
- Пояснения в карточке урока: «Недавнее — то, что вы выучили за последние дни», «Старое — давно выученное, чтобы не забылось» (`LessonCardCopy.recentHint`, `oldHint`).

## Открыто (нужна проверка носителями)

- В таджикском, узбекском и турецком у «повтор звука» и «повторение выученного» один корень (такрор / takror / tekrar). Различие держится на форме и контексте: существительное — звук, глагол — выученное. Отдельное слово для «review» стоит подобрать с носителем (варианты: тадж. «мурур», узб. «qayta ko‘rib chiqish»).
- Тест: во всех трёх языках заимствование «Test»; в тадж. и узб. возможны «Имтиҳон» / «Imtihon».
- Турецкое «Sınama» осталось только за скрытием текста; тест — «Test».
- Старая строка «Режим экзамена» в общем коде (`AppStrings`, iOS) — третье имя скрытия текста, не тронута.
- «Проверьте себя» в русском — это вежливая форма прежнего «Проверь себя»; если владелец хочет оставить прежнюю форму названием режима, поправить `HifzCopy` и `ReaderCopy`.
