# iOS Pro — решения и список задач

Дата: 2026-11-15. Основа — `IOS_PRO_PLAN.md`. Владелец поручил решить самому; ниже решения и задачи по порядку.

## 1. Решения (приняты 2026-11-15)

**Покупки — как в CleanSwipe.** В CleanSwipe уже работает связка, которая подходит продавцу из Таджикистана: соглашение
Paid Apps, налоги и банк в App Store Connect, ключ In-App Purchase (`.p8`) в RevenueCat, entitlement `premium`, offering `default`,
публичный ключ `appl_…` в release и ключ Test Store только в Debug (переменная схемы `REVENUECAT_API_KEY`). Повторяем то же для
Quran Hifz (отдельное приложение App Store и свой ключ в RevenueCat). Из CleanSwipe **не берём**: страницу покупки на каждом
холодном старте и недельный тариф.

**Чтобы пользоваться могли все:**
- приложение доступно во всех странах App Store, включая Россию и Таджикистан;
- **бесплатная версия полная**: весь урок дня, чтение, мусхаф, чтецы, таджвид, переводы, тесты, аналитика, отчёт, виджет — и
  из нового «Следить за чтением» без лимита, «Найти аят голосом» и одна проверка голосом в день;
- Hifz+ добавляет только новое (проверка наизусть без лимита, урок голосом, история ошибок, умное повторение);
- распознавание работает без интернета;
- цены низкие (ниже), для Таджикистана, Узбекистана и бедных стран — минимальные;
- кто не может платить — бесплатный код по письму (медресе — пачкой);
- доступность: VoiceOver, крупный шрифт, iPad, новые языки (арабский, индонезийский).

**Цены** (изменено против плана: ниже, ради охвата; та же годовая цена, что у CleanSwipe):

Индонезия, Пакистан, Египет, Бангладеш, Индия — как Таджикистан. Россия — цена по пересчёту Apple (платить там сейчас почти
нельзя, но приложение доступно бесплатно). Пересмотр через месяц после 2.1.

**Остальные решения §15 плана — по рекомендации:** (1) в Hifz+ только новое; (2) следование бесплатно, 1 проверка в день;
(4) RevenueCat; (5) диктофон убрать на iOS и Android; (6) сначала 2.0 без подписки, потом 2.1; (7) арабский и индонезийский
первыми; (8) iPad оставить и довести; (9) семейный доступ Apple пока не включать; (10) названия «Hifz+», «Следить за чтением»,
«Проверьте себя голосом», «Прочитать вслух»; (11) движок на Android — после итогов 2.1; (12) коды для тех, кому трудно платить;
(13) шаг «Прочитайте Аль-Фатиху» в онбординге; (14) Firebase Analytics и Crashlytics на iOS только с согласия.

## 2. Задачи

Обозначения: **Б** — делает удобнее бесплатную версию; **+** — относится к Hifz+. Объём: S — до 2 дней агента, M — до недели,
L — больше. Одновременно не больше трёх агентов и двух симуляторов; агент удаляет свой симулятор и DerivedData вне репозитория.
