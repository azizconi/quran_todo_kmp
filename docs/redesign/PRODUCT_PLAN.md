# Quran Hifz — разбор по фичам и план доведения продукта

Дата: 2026-10-28. Основа: полный аудит кода ветки `redesign/android` (данные и API, логика заучивания, звук/напоминания/бэкап/аналитика/релиз), проверка живых API запросами, приёмка экранов на эмуляторе. Визуальный редизайн (`ANDROID_REDESIGN.md`) остаётся в силе; этот документ — про **смысл и полезность** приложения.

## 0. Коротко

**Что приложение должно делать.** Быть ежедневным спутником в заучивании Корана: каждый день показывать **один понятный урок** — выучить немного нового, повторить недавнее, освежить старое — и не давать забыть выученное. Чтение и прослушивание — основа, на которой это стоит.

**Что сейчас.** Красивая читалка с плеером и слоем «статусов», который почти ничего не делает:

1. Повторения невозможно завершить: в живом UI нет оценки «вспомнил / забыл». Интервал повторения у любого аята навсегда остаётся 1 день.
2. «Выучено» на суре не создаёт ни одного повторения — такая сура больше никогда не всплывёт. Это ровно тот путь, которым придёт человек, уже знающий часть Корана.
3. Блок «Сегодня» никогда не заканчивается: выучил 3 аята — он предлагает следующие 3. Цель «аятов в день» реально режется до 3 скрытой настройкой без UI.
4. Нет плана: нельзя сказать «учу Джуз Амма» и понять, когда закончу.
5. Звук с выключенным экраном нестабилен: нет фонового сервиса, уведомления, реакции на звонок и отключение наушников.
6. Напоминания принудительно выключаются при каждом запуске; разрешение на уведомления не запрашивается.
7. «Резервная копия» — файл на этом же телефоне: удалил приложение — всё пропало; на другой телефон не перенести.
8. Первый запуск без интернета — приложение пустое; таджикский и узбекский получают английские названия сур; узбекский перевод — кириллица при латинском интерфейсе.
9. База данных без миграций — **любое изменение схемы уронит приложение у пользователей Play**.
10. Ключ подписи и релизный AAB лежат в git; Firebase-аналитика работает без согласия, политика конфиденциальности о ней молчит и содержит заглушки `[YOUR_EMAIL_HERE]`.

**Стратегия.** Не «добавить ещё фич», а замкнуть один цикл и сделать его безупречным:

```
Онбординг: цель → что уже знаю → что учу и в каком темпе → напоминание
      ↓
Каждый день: напоминание → «Урок дня» на главном → Новое → Недавнее → Старое → «На сегодня всё»
      ↓
Прогресс растёт честно: карта Корана, серия дней, «Джуз Амма закончу ~14 марта»
```

Всё, что не служит этому циклу или чтению/слушанию, — убрать или отложить.

## 1. Продукт

**Для кого.** Русско-, таджико-, узбеко- и турецкоязычные мусульмане, которые:
- заучивают Коран сами (чаще всего начиная с Джуз Амма), по 3–10 аятов в день;
- учатся у устаза в медресе/мечети и должны приносить выученное и повторение;
- просто читают и слушают Коран и хотят вернуться туда, где остановились.

**Обещание (первая фраза на экране и в сторе).** «Заучивайте Коран каждый день — понемногу и без забывания».

**Три опоры:**
1. **Читать** — красивый текст мусхафа, перевод, крупный шрифт, навигация по сурам и джузам.
2. **Слушать** — чтецы, повтор отрывка, паузы, скорость, работает с выключенным экраном.
3. **Заучивать** — план, урок дня, повторение по проверенной схеме (новое → недавнее → старое), честный прогресс.

**Чего в приложении нет и не будет** (чтобы не расползаться): времена намаза, кибла, лента, соцсети, рейтинги, баллы.

**Метод (основа «Урока дня»)** — традиционная схема хифза:
- **Сабак (новое)** — небольшой непрерывный отрывок, который учим сегодня.
- **Сабки (недавнее)** — отрывки последних недель, повторяются часто (лестница +1, +3, +7, +14, +30 дней).
- **Манзиль (старое)** — всё прочно выученное, проходит по кругу, чтобы ничего не забылось.

## 3. Новое ядро: «Мой план» и «Урок дня»

### 3.1 Модель данных (Room, миграция 10 → 11, только добавление таблиц)

```
hifz_plan       id, scope (JUZ_30 | JUZ_29 | FROM_START | CUSTOM), surahOrder: List<Int>,
                dailyNewAyahs, targetEpochDay?, startedEpochDay, active
hifz_passage    id, surah, startAyah, endAyah (номера в суре), learnedEpochDay,
                stage (NEW | RECENT_0..4 | OLD), nextDueEpochDay, lapses, lastReviewedEpochDay
passage_hard    passageId, ayahInSurah, clearedAfter (сколько успешных повторений осталось)
review_log      id, passageId?, surah, startAyah, endAyah, kind (NEW | RECENT | OLD | CHECK),
                grade (FORGOT | HARD | GOOD | EASY), epochDay, timestamp
```

- Перед изменением схемы — экспорт текущей схемы v10 (`exportSchema = true`) и тест миграции. Миграция затрагивает и iOS (общая БД): только `CREATE TABLE`, iOS-сборку проверить (`compileKotlinIosSimulatorArm64`).
- **Перенос данных существующих пользователей:** выученные суры/аяты → отрывки в `OLD`; аяты «заучиваю» → отрывки `RECENT_0` со сроком «сегодня»; старые `ayah_review` — по сроку в лестницу. Старые таблицы не удаляются (их читает iOS).
- Статус суры для UI = из отрывков: все аяты покрыты → «Выучено», есть отрывки → «Заучиваю».

### 3.2 Планировщик (чистые функции + unit-тесты)

- **Новое:** следующие `dailyNewAyahs` аятов плана, одним непрерывным отрывком внутри одной суры (если сура кончается раньше — короче; короткие суры Джуз Амма целиком, если ≤ темпа × 1.5). Если новое сегодня уже сделано — блок закрыт.
- **Недавнее (лестница):** этапы +1, +3, +7, +14, +30 дней. «Легко» → через этап, «Хорошо» → следующий, «Трудно» → тот же этап снова, «Забыл» → +1 и отметка трудных аятов. После этапа +30 → `OLD`.
- **Старое (круг манзиль):** все `OLD`-отрывки упорядочены по мусхафу и делятся на `N` дней (по умолчанию 7, настраивается 3–30); каждый день — своя порция, круг гарантирует полное покрытие. «Трудно/Забыл» возвращают отрывок в лестницу.
- **Бюджет:** если накопились просрочки — сначала недавнее (самое хрупкое), затем старое; урок никогда не больше ~25 минут (оценка по длине аятов × повторам), остальное переносится с пометкой «догоняем».
- **Прогноз:** «Джуз Амма закончу ~14 марта при 5 аятах в день»; при сроке — нужный темп и предупреждение «отстаёте на 12 аятов».
- Всё по календарным дням в часовом поясе устройства; смена дня — по полуночи (обновление при возврате в приложение и по таймеру).

### 3.3 Экран «Урок» (новый маршрут `Dest.Lesson`)

Пошаговый поток, сверху — три шага урока с прогрессом:

1. **Новое**
   - «Послушай» — отрывок крупно, каждый аят звучит 3× (настраивается), затем весь отрывок 2×; текущий аят подсвечен; можно перейти дальше в любой момент.
   - «Прочитай» — текст виден, нажатие на аят — проиграть его.
   - «Вспомни» — текст скрыт (размытие, подсказка первого слова по настройке), удержание — подсмотреть, «Показать» — открыть по аяту; в конце оценка отрывка и отметка трудных аятов касанием.
2. **Недавнее** — карточка на отрывок: скрыт → вспомнить → показать → оценка; «🎧» — послушать перед попыткой.
3. **Старое** — то же, порция круга.
4. **Итог** — кольцо, разбивка, серия дней, прогноз плана, «Завтра: …»; праздник частицами — только когда урок реально закрыт.

Режим заучивания (2A, `ui/hifz`) переиспользуется как компонент шага «Вспомни»; в ридере он же — режим «Проверь себя» (оценки пишутся как `CHECK` в журнал, без изменения лестницы, если отрывок не к повторению).

### 3.4 Главный экран при цели «Заучивать»

Первая карточка — **«Урок дня»**: три строки с галочками (Новое: Ан-Наба 1–5 · Недавнее: 3 отрывка · Старое: Аль-Мульк), оценка времени «~12 мин», кнопка «Начать урок» / «Продолжить урок» / «Урок выполнен ✓ · завтра: …». «Продолжить чтение» — второй, компактнее. Для цели «Читать и слушать» порядок обратный и урок предлагается одной строкой-приглашением.

Лист суры: «Не начал / Учу / Знаю наизусть». «Знаю наизусть» создаёт отрывки в старом; «Учу» добавляет суру в план.

## 4. Онбординг v2

Цель: за 60–90 секунд человек понимает, **что это и что ему даст**, и выходит с готовым планом и первым уроком. Каждый экран — один вопрос; индикатор шагов; «Назад» работает; язык — первым, потому что от него зависит весь текст.

| # | Экран | Содержание и движение |
|---|---|---|
| 1 | Язык | Рисующаяся розетка (уже есть), 5 языков, мгновенная смена текста |
| 2 | «Читайте красиво» | Мини-ридер: строки Аль-Фатихи проявляются, розетки аятов «расцветают» |
| 3 | «Слушайте и повторяйте» | Пульсирующая кнопка ▶, кольцо повтора «1–5 · 3×» обходит отрывок, волна звука |
| 4 | «Заучивайте и не забывайте» | Аят размыт → проявляется; под ним календарь лестницы +1 +3 +7 +14 загорается по дню |
| 5 | Ваша цель | Две большие карточки: «Заучивать Коран» / «Читать и слушать» |
| 6 | Что уже знаете? (если заучивать) | Сетка коротких сур (Аль-Фатиха, 114 → 78) — касание отмечает; «Другие суры» — поиск; «Пока ничего» |
| 7 | Что будем учить? | Пресеты: «Джуз Амма (с конца)», «Джуз Табарак», «С начала Корана», «Выбрать суры» — с первой сурой урока и числом аятов |
| 8 | Темп | Слайдер 1–10 аятов в день с живым прогнозом «≈ 4 месяца»; переключатель «Хочу к дате» с выбором даты → нужный темп |
| 9 | Напоминание | Время (по умолчанию 07:00), предпросмотр уведомления; кнопка «Напоминать» запрашивает разрешение **здесь**, «Не сейчас» — без запроса |
| 10 | Как удобнее читать | Превью аята, шрифт (карусель), размер, тема (свет/тьма/система) — один экран вместо трёх |
| 11 | План готов | Карточка-итог: «Урок 1: Ан-Нас 1–6 · ~6 мин», «Знаете: 5 сур — будем повторять», прогноз; строка про анонимную статистику с тумблером; кнопка **«Начать первый урок»** (сразу в урок) и «Позже» |

Для цели «Читать и слушать»: 1–5 → 10 → 11 («Начните с Аль-Фатихи»). Существующие пользователи: онбординг не повторяется, но при первом запуске новой версии — короткий экран «Новое: Урок дня» с предложением создать план (из их текущих статусов он уже собран миграцией).

Слайды 2–4 можно пролистать свайпом и пропустить; анимации уважают Reduce Motion (статичные иллюстрации).

## 5. Спотлайты (подсказки на экранах)

### 5.1 Компонент (`ui/components/spotlight/`)

- `SpotlightHost` — слой в корне приложения поверх навигации.
- `Modifier.spotlightTarget(id)` — регистрирует границы элемента (в координатах корня) и его форму (круг/скругление).
- Тур — список шагов: `targetId`, заголовок, текст, форма, позиция подсказки (авто сверху/снизу), опциональное действие «Попробуйте».
- Вид: затемнение `scrim` 70% с вырезом вокруг цели; вырез **перетекает** пружиной от цели к цели; вокруг цели мягкое пульсирующее кольцо; карточка-подсказка со стрелкой, «Далее · 2/4», «Пропустить»; лёгкая вибрация на шаг.
- Касание вне карточки — следующий шаг; «Назад» — закрыть тур. TalkBack: текст шага объявляется, кнопки доступны.
- Показ один раз (флаги в `UiPrefs`), туры не запускаются поверх листов и во время переходов; «Показать подсказки снова» — в настройках.
- Reduce Motion: без перетекания и пульса.

### 5.2 Туры

| Тур | Когда | Шаги |
|---|---|---|
| Главный | Первый показ главного после онбординга | «Урок дня» → «Продолжить чтение» → удержание суры («так отмечают, что знаете суру») → кольцо прогресса |
| Ридер | Первое открытие суры | Нажатие на аят («слушать с этого аята») → удержание аята (заметка, статус, поделиться) → док плеера («потяните вверх: повтор отрывка, паузы, скорость») → «Aa» → «Проверь себя» |
| Урок | Первый урок | Шаги урока сверху → «удерживайте, чтобы подсмотреть» → кнопки оценки («честная оценка = точное расписание») |
| Плеер | Первое раскрытие дока | Повтор отрывка → пауза между аятами |
