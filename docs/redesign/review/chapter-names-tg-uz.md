# Названия сур для tg и uz: список на проверку носителем

Файлы `chapter_names_tg.json` (кириллица) и `chapter_names_uz.json` (латиница) собраны скриптом `scripts/build_chapter_names.py` из таблицы `NAMES` в нём. Названия составлены вручную и **ещё не проверены носителем**.
Исправления вносятся в `NAMES`, затем скрипт запускается заново (он перезапишет оба JSON и этот файл).

Формат ячейки: «написание названия / смысл названия». Договорённости: арабский артикль «ал-» не пишется (Фотиҳа, Fotiha); таджикский — ҳ ҷ қ ғ ӯ, знак ъ для ع и хамзы; узбекский — o‘ и g‘ через U+2018, тутуқ белгиси через U+2019 (An’om, Ra’d).
