## Правки

1. **«Сегодня → Новое» предлагает уже повторённые аяты.** После сессии заучивания по Аль-Фатихе (все 7 аятов оценены) карточка «Новое» снова показывает «Аль-Фатиха, аяты 1–3». Правило:
   - «Новое» = аяты со статусом LEARNING, у которых **нет ни одной записи** `AyahReviewEntity` (никогда не повторялись), плюс следующие по порядку аяты сур «Заучиваю» без статуса — до дневной цели минус уже сделанное сегодня;
   - аят с записью ревью попадает только в «Повторить» (когда `nextReviewAt <= now`) или «Слабые места»;
   - если сегодняшняя цель уже выполнена (`doneToday >= goal`), «Новое» не показывается.
   Обнови `TodayPlanner` и его тесты (добавь случай «после сессии»).
2. **Заголовок карточки обрезается** («Слабые мес…»). Заголовки карточек «Сегодня» — до 2 строк, карточки одной высоты; проверь все 5 языков (самые длинные — TG/UZ).
3. **Цель перевыполнена: «7 из 5».** При `doneToday >= goal` показывай состояние «цель выполнена»: кольцо полностью залито + галочка (`AnimatedCheckmark`), подпись «Цель выполнена · 7» (5 языков), однократный `CelebrationBurst` маленького радиуса при первом достижении цели за день (флаг на дату в `HomeLocalPrefs`).
4. **TalkBack: у строки суры не озвучивается статус.** Добавь в семантику строки `stateDescription`: «Не начал» / «Заучиваю, выучено 40%» / «Выучено» (5 языков; формат процента — как в `ProgressCopy`). То же для чипов «Недавние» с закреплением («Закреплено»).
5. **Крупный шрифт (1.3×): подпись строки суры обрезается** («Открывающая Коран · 7 ая…»). При `fontScale > 1.15` разреши подписи 2 строки; при обычном — одна строка с многоточием, как сейчас.
6. **Онбординг, шаг «Оформление»:** смена темы/палитры — через `rememberThemeSwitcher()` с круговым раскрытием из точки касания, как в настройках.
