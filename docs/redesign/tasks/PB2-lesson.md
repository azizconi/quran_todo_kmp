## Что сделать

### 1. Общий компонент «Вспомни» (P0)

Один компонент для урока и ридера, на основе 2A (`HifzAyahContent`, `HifzControls`, `HifzSession`):
- аяты отрывка скрыты (размытие; подсказка первого слова — `UiPrefs.hifzHintMode`), по одному: «🎧» (послушать этот аят), «Показать», удержание — подсмотреть;
- после показа — **две** кнопки: «Помню» / «Трудно» (вместо четырёх оценок на аят). «Трудно» отмечает аят трудным;
- после последнего аята — лист оценки отрывка: 4 оценки (Забыл, Трудно, Хорошо, Легко) с предложенной: все «Помню» → Хорошо; есть «Трудно» → Трудно; «Трудно» у половины и больше → Забыл. Человек может выбрать другую. Ниже — трудные аяты чипами, касание снимает/ставит отметку.
- Предложение оценки — чистая функция + unit-тест.

### 2. Экран «Урок» (`Dest.Lesson`, P0)

Состояние — из `HifzRepository.lesson(today)` (день — `EpochDayTicker`); каждое действие пишется сразу (`completeNew`, `review`), поэтому выход посреди урока ничего не теряет, а возврат продолжает с первого несделанного.

- **Шапка:** «Урок дня», три шага (Новое · Недавнее · Старое) с прогрессом и галочками, оставшиеся минуты. Пустой блок не показывается. «Догоняем» — тихая плашка, если `catchingUp`.
- **Новое** — три фазы с переходами между ними:
  - «Послушай»: отрывок крупно, каждый аят звучит N раз (по умолчанию 3), затем весь отрывок M раз (по умолчанию 2), текущий аят подсвечен и прокручивается в центр; «Дальше» — в любой момент. N и M — в маленьком листе настроек урока (`UiPrefs.lessonAyahRepeats`, `lessonPassageRepeats`).
  - «Прочитай»: текст виден, касание аята — проиграть его.
  - «Вспомни»: компонент из п. 1 → `completeNew`.
- **Недавнее** и **Старое**: по одному отрывку за раз («2 из 5»), карточка с названием суры и диапазоном, «🎧 послушать сначала», затем «Вспомни» → `review`. Переход между отрывками — горизонтальный слайд (motion из `ui/motion`).
- **Итог:** кольцо (сделано / всего), разбивка по шагам, серия дней (`streak`), прогноз плана (`forecast`), «Завтра: Ан-Наба 6–10 и 3 повторения» (из `LessonPlan`). Праздник (`Celebration`) — только если урок закрылся в этот заход. Кнопка «На главный».
- **Пусто:** нет плана и нечего повторять → `EmptyState` «Составьте план, и здесь появится урок» с кнопкой → `Dest.Plan` (добавь параметр `onOpenPlan` в `LessonScreen` и в запись NavHost). Всё сделано (открыли повторно) → итог.
- **Вход:** контейнер-переход из карточки «Урок дня» главного (её делает B3 с ключом `SharedKeys.LessonCard` на `sharedBounds`; сделай то же на корне экрана урока).
- **Назад** посреди «Вспомни» с открытыми аятами — вопрос «Выйти из урока? Сделанное сохранено».
- Положение внутри шага (фаза, аят) переживает поворот и смерть процесса (`SavedStateHandle`).
- **Звук** — общий `PlaybackController`. Повторы урока не должны портить настройки ридера человека: посмотри, как это делает `HifzViewModel` (сохраняет и возвращает), а лучше добавь в `PlaybackController` явный аддитивный вызов «проиграть диапазон с N повторами аята и M повторами отрывка» (секвенсор `ReaderAudioSession` уже умеет повторы и диапазон). Мини-плеер и уведомление должны вести себя как при обычном прослушивании.
- **Аналитика** (`AppTelemetry.logEvent`, без свободного текста): `lesson_started`, `lesson_block_done` (`block`=new|recent|old), `lesson_completed` (`minutes_bucket`), `check_completed` (`grade`).

### 3. Ридер (P0)

- Режим заучивания становится **«Проверь себя»**: тот же компонент «Вспомни» по выбранному диапазону (входы, которые уже есть в ридере, и `Dest.Reader(hifz = true, rangeStart, rangeEnd)` работают как прежде). В конце: если диапазон в точности совпадает с отрывком, который сегодня в уроке и не сделан, — `review` этого отрывка, иначе `logCheck`.
- Лист суры в ридере, страница статуса: «Не начал / Учу / Знаю наизусть» — `forget` / `learnNext` / `markKnown`; текущий статус — производный (`surahStatuses`). «Не начал» при выученных аятах — подтверждение «Убрать N выученных аятов из повторений?».
- Лист аята: строка состояния из `surahCoverage` (выучен / трудный / «повторение через N дней» или «в круге старого»), действия «Знаю этот аят» / «Убрать из выученных» (`markKnown`/`forget` на один аят), «Проверь себя отсюда».
- Отметки трудных аятов в ридере — из `surahCoverage` (вместо слабых ключей prefs).

1. `./gradlew :composeApp:assembleDebug`, `./gradlew :composeApp:testDebugUnitTest`. Unit-тесты: предложение оценки, переходы фаз урока (чистая модель шага), выбор «review или logCheck» в ридере.
2. На эмуляторе, со скриншотами (светлая и тёмная тема, хотя бы один экран при шрифте 1.3×):
   - план создай вызовом репозитория из отладочного кода или через уже готовый экран B3, если его ещё нет — временной отладочной кнопкой, **которую удалишь до коммита**; либо `markKnown` + существующие отрывки после переноса B1;
   - полный урок: новое (все три фазы, звук идёт, подсветка аята), недавнее, старое, итог с праздником; выйти посреди урока и вернуться — продолжается с места;
   - на следующий день (`adb shell date` нельзя без root — поменяй день через подменяемый источник дня в отладочной сборке или проверь unit-тестом) — достаточно unit-теста;
   - «Проверь себя» в ридере → запись в журнал (`adb shell run-as tj.app.quran_todo sqlite3` или отладочный лог), статусы в листе суры и аята меняются;
   - мини-плеер/уведомление во время «Послушай»; после урока настройки повторов в ридере прежние.
3. Холодный старт и прокрутка ридера не стали медленнее (сравни с базовой сборкой при той же нагрузке; машина сильно загружена — сравнивай только относительно).
