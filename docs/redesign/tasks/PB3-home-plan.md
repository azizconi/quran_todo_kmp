## Что сделать

### 1. Карточка «Урок дня» (P0)

Вместо старого раздела «Сегодня» (`TodaySection`, `TodayPlanner` и их тесты — удали, если больше нигде не нужны).
- Три строки с галочками: «Новое: Ан-Наба 1–5», «Недавнее: 3 отрывка», «Старое: Аль-Мульк 1–15» (название суры по языку интерфейса, как в остальном главном); пустой блок не показывается. Оценка «~12 мин».
- Кнопка: «Начать урок» → «Продолжить урок» (что-то уже сделано) → «Урок выполнен ✓ · завтра: …». «Догоняем» — тихая пометка при `catchingUp`.
- Нет плана и нечего повторять → приглашение «Составьте план — каждый день будет готовый урок» → `Dest.Plan`. План выполнен → «План выполнен 🌿» + «Новый план».
- Переход в урок: `sharedBounds` с ключом `SharedKeys.LessonCard` (B2 делает тот же ключ на экране урока) + `navigate(Dest.Lesson)`; HomeScreen получает `onOpenLesson`, `onOpenPlan`.
- Порядок на главном: при цели «Заучивать» (`UiPrefs.onboardingGoals` содержит `MEMORIZE` или цели не выбраны) — «Урок дня» первым, «Продолжить чтение» вторым и компактнее. Иначе — «Продолжить чтение» первым, а урок — одной строкой-приглашением.
- Длинное нажатие или «⋯» на карточке → «Мой план».

### 2. Экран «Мой план» (`Dest.Plan`, P0)

Стиль экранов настроек (`QhLargeTopBar`, карточки-разделы, вход с общим переходом навигации).
- **Что учу:** Джуз Амма (114 → 78), Джуз Таборак (77 → 67), С начала (1 → 114), Свои суры. Для пресета — очередь только для чтения + «Изменить порядок» (превращает в «Свои»). Для «Свои» — список сур: добавить (поиск по названию/номеру — переиспользуй `SurahSearch`), убрать, перетащить. Выученные суры в очереди — серые с галочкой.
- **Темп:** аятов в день 1–20 (`Wheel`) **или** «Закончить к дате» (DatePicker) → показывается нужный темп. Переключатель между двумя режимами. Под темпом — оценка времени нового отрывка у текущей суры (`HifzRepository.estimateMinutes(…, isNew = true)`): «≈ 5 минут в день»; если больше `HifzConstants.LESSON_BUDGET_MINUTES` — мягкое предупреждение «Это около 70 минут в день — урок будет длинным».
- **Круг старого:** «Повторять всё выученное за N дней», 3–30 (по умолчанию 7), с подписью «≈ 1,5 страницы в день» = `oldWeight() / HifzConstants.CHARS_PER_PAGE / N` (нет выученного — подписи нет).
- **Прогноз** обновляется вживую: «Закончите ~14 марта», при сроке — «нужно 7 аятов в день», отставание — «отстаёте на 12 аятов».
- Сохранение — `setPlan` по кнопке «Сохранить» (или автосохранение с отменой — выбери одно и объясни). «Удалить план» — с подтверждением (`clearPlan`; выученное остаётся).

### 3. Лист суры на главном (P0)

- Статус: «Не начал / Учу / Знаю наизусть» → `forget` / `learnNext` / `markKnown`. Показ — производный (`surahStatuses`). «Не начал» при выученных аятах — подтверждение «Убрать N выученных аятов из повторений?». **Та же семантика**, что B2 делает в листе суры ридера.
- Под статусом — строка покрытия: «Выучено 23 из 40 аятов · 2 трудных».
- Множественный выбор в списке («Отметить выученными» и т. п.), если есть, — через те же функции.

### 4. Список сур

- Статус и доля выученного в строке, фильтр «Учу/Выучено» — из `surahStatuses` и покрытия B1 (одна подписка на всё, без 114 подписок).
- Текущая сура плана — маленькая метка «в плане».

### 5. Смена дня

`EpochDayTicker.refresh()` на ON_RESUME процесса (`ProcessLifecycleOwner` или lifecycle Activity в `QuranHifzApp.kt`), чтобы карточка урока менялась после полуночи без перезапуска.
