## Что сделать

### 1. Формат файла (P0)

JSON (`kotlinx.serialization`), имя `quran-hifz-ГГГГ-ММ-ДД.json`:
```
format: "quran-hifz-backup", formatVersion: 1, appVersion, exportedAt (мс), dbVersion: 11,
hifz: { plan?, passages[], hard[], reviewLog[], meta{} },
notes: [ayah_note…],
settings: { …то, что человек настраивал: язык, тема/палитра, шрифт и размер, ридер, чтец, повторы урока, подсказка первого слова, аналитика НЕ переносится }
```
- Старые таблицы (`surah_todo`, `ayah_todo`, `ayah_review`) не пишутся: после импорта их пересчитывает зеркало B1 по всем сурам.
- Экспорт — снимок из одной транзакции чтения.
- Чистые функции «снимок → JSON» и «JSON → проверенный снимок» с ошибками по видам: не наш файл; версия формата новее (просим обновить приложение); повреждён; данные вне диапазонов (сура 1..114, аяты в пределах суры по `QuranFacts`, этапы из перечня). Неизвестные поля игнорируются (вперёд-совместимость).

### 2. Импорт (P0)

- Выбор файла (`ACTION_OPEN_DOCUMENT`, `application/json` и `*/*`), разбор вне главного потока.
- Предпросмотр перед заменой: «Копия от 12 марта 2026: план «Джуз Амма», 34 отрывка, 2 трудных аята, 120 заметок. Текущие данные на этом телефоне будут заменены» — «Заменить» / «Отмена».
- Замена — **одна транзакция**: таблицы хифза и заметки удаляются и вставляются, затем зеркало по всем сурам, `hifz_meta.legacy_import = done` (чтобы старый перенос не запустился поверх). Ошибка в середине — прежние данные целы, тост с причиной.
- Настройки из файла применяются после успешной замены (через существующие сеттеры `UiPrefs`/`UserSettingsStorage`; язык и тема — так же, как это делает экран настроек сейчас при восстановлении).

### 3. Экспорт (P0)

- «Сохранить копию в файл» (`ACTION_CREATE_DOCUMENT`) и «Отправить копию» (`ACTION_SEND` через `FileProvider`, временный файл в `cacheDir`, удаляется при следующем экспорте) — например, себе в Telegram или в Google Drive.
- Тост «Копия сохранена» / ошибка.

### 4. Настройки (P0)

- Раздел «Перенос и копия» вместо строк старой копии в prefs: «Сохранить копию в файл», «Отправить копию», «Восстановить из файла», под ними одна строка пояснения «Прогресс хранится на этом телефоне. Android также сохраняет его в вашем аккаунте Google, если резервное копирование включено». Старые строки и их тосты убери с Android-экрана.
- Последний экспорт: «Последняя копия: 12 марта» (дата в `UiPrefs`).
- Тексты — 5 языков (ru, en, tg, uz, tr).
