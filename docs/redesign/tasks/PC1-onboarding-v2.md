## Правило записи

- **Язык, шрифт, размер, тема и палитра** применяются сразу, через сеттеры корня, как сейчас.
- **Напоминание** включается на шаге 9 через `ReminderController`.
- **Цель** записывается в `UiPrefs.onboardingGoals` на шаге 5: «Заучивать» → `{MEMORIZE}`, «Читать и слушать» → `{READ, LISTEN}`.
- **Прогресс заучивания** до последнего экрана **ничего не пишет**. Выбор (что знаю, что учу, темп) живёт в VM и в `SavedStateHandle`. По кнопке последнего экрана — одной корутиной:
  1. `markKnown` для каждой отмеченной суры;
  2. `setPlan(...)`;
  3. флаг «онбординг пройден»;
  4. переход.

  Ошибка записи → тост, экран остаётся.

## Шаги

Каждый экран — один вопрос. «Назад» (вверху и системный) возвращает на предыдущий шаг; на шаге 1 системный «назад» выходит из приложения. Индикатор шагов — тонкая сегментная полоса; число сегментов зависит от пути, слайды 2–4 — один сегмент. Переходы — shared axis X из `ui/motion`. Кнопка шага прибита к низу, содержимое прокручивается (шрифт 1.3×, экран 360×640 dp).

**Слайды 2–4:**

Первый урок и прогноз на шагах 7, 8 и 11 считаются **без записи** — чистыми функциями B1/B3. Это `NewPassagePlanner`, прогноз из `PlanMath` и `estimateMinutes` (только чтение). Отмеченные суры планировщик должен пропускать — проверь тестом, что первый урок не попадает в отмеченную суру.

## Кто проходит онбординг

- **Флаг завершения.** Добавь явный флаг `UiPrefs.onboardingCompleted` и статическое чтение без Koin (как `readAnalyticsEnabled`): сплэш и `MainActivity` зовут `needsOnboarding()` до Koin.
- **Решение — чистая функция с unit-тестом:**
  - пройден → не показывать;
  - не пройден, язык и шрифт сохранены прошлой версией, и онбординг v2 не начинался → **существующий пользователь**: не показывать, флаг поставить;
  - во всех остальных случаях → показать.

  Существующие пользователи (обновление с Play 1.0.x и прошлых сборок редизайна) **никогда** не должны увидеть онбординг снова.
- **Прерванный онбординг** (смерть процесса) продолжается с того же шага: шаг и выбор хранятся в `SavedStateHandle`. Если процесс убит полностью, допустимо начать заново, но без двойных записей.

## «Новое: Урок дня» для существующих пользователей

Разовый лист (`QhSheet` — C2 не запускает подсказки поверх листов) над главным, при первом запуске этой версии:
- **Текст** — 2–3 строки о «Уроке дня» и плане.
- **Кнопка:**
  - план есть (перенос B1 собирает его из старых статусов) → «Открыть урок» (`Dest.Lesson`);
  - плана нет → «Составить план» (`Dest.Plan`);
  - «Позже».
- **Когда показывать.** Один раз (флаг в `UiPrefs`). Не показывать:
  - новым пользователям, прошедшим v2;
  - поверх ссылки из напоминания — тогда отложить до следующего запуска.
- **Где.** В `QuranHifzApp` / `ui/whatsnew/`, не в `ui/home/**`.

## Аналитика (без свободного текста)

- `onboarding_step` (`step` — имя шага из перечня);
- `onboarding_story_skipped`;
- `onboarding_completed`:
  - `goal` = memorize|read;
  - `preset`;
  - `pace` (число);
  - `known` = 0|1-3|4-10|11+;
  - `reminder` = on|off;
  - `action` = lesson|later|reader;
- `whats_new_shown`, `whats_new_action` (`action` = lesson|plan|later).
