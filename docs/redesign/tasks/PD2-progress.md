## Что сделать

### 1. Экран «Прогресс» на модели хифза (P1)

Все цифры — из `HifzRepository` (день — `EpochDayTicker`); старые таблицы и prefs не читаются.

- **Кольцо (герой):** выучено аятов (покрытие) из 6236, процент (меньше 1 % — «меньше 1 %»), «Знаю наизусть: N сур · Учу: M». Общий элемент с кольцом шапки главного сохраняется.
- **Плитки:**
  - серия дней (`streak`);
  - сегодня: «Урок выполнен» или «Осталось 2 из 5» (`lesson`);
  - удержание за 30 дней — доля повторений (RECENT, OLD, CHECK) без «Забыл»; нет данных — «—»;
  - трудных аятов сейчас (отметки в отрывках).
- **Активность за 30 дней:** столбики по дням из `reviewLog` — аятов выучено (новое) и повторено, двумя тонами. Пустые дни видны. Касание столбика — подпись дня.
- **Карта Корана:** 114 ячеек — статус и доля выученного (`surahStatuses`, `coveredCounts`); касание → ридер.
- **Джузы:** 30 полосок — доля выученного (`coveredAyahs` + `JuzIndex.coveredCount`); касание → ридер с начала джуза.
- **План:** «Джуз Амма: закончите ~16 февраля», «отстаёте на 12 аятов» / «идёте с опережением» (`forecast`); нет плана — строка-приглашение → `Dest.Plan`.
- **Трудные места:** суры с трудными аятами, чипы аятов; касание → ридер на аяте. Слабых ключей из prefs больше нет.
- **Пусто** (ничего не выучено и нет журнала) — `EmptyState` с кнопкой «Составить план».
- Экран переживает смену дня: `ticker.refresh()` на ON_RESUME, как на главном.

### 2. Отчёт для устаза (P1)

Кнопка «Поделиться отчётом» (в шапке или внизу экрана) → лист выбора «За неделю / За месяц» → отправка через `ACTION_SEND`:

- **Текст** (5 языков, без эмодзи-звёзд):
  - заголовок и период;
  - выучено новое — диапазоны по сурам: «Аль-Масад 1–5»;
  - повторено — число и список сур;
  - трудные аяты;
  - серия;
  - прогноз плана.

  Названия сур — по языку интерфейса. Готов для Telegram или WhatsApp.
- **Картинка:** та же сводка карточкой в стиле приложения (светлая тема, каллиграфия «حفظ», без звёзд), отрисованная в PNG. Например, Compose `GraphicsLayer.toImageBitmap()` или `View` вне экрана — выбери надёжный способ и объясни. Файл — во временной папке `cacheDir` через существующий `FileProvider`; предыдущий удаляется при следующей отправке.
- По умолчанию отправляются **и текст, и картинка** в одном `ACTION_SEND`: `EXTRA_TEXT` + `EXTRA_STREAM`, `image/png`.
- Чистая функция «журнал + покрытие + план → модель отчёта» и функция «модель → текст» — с unit-тестами.
