## Что сделать

### 1. Демо-состояние

Человек заучивает Джуз Амма, знает Аль-Фатиху и 10 коротких сур, сделал несколько уроков: есть серия, журнал и «трудные» аяты. Наполни через UI: онбординг, уроки, отметки сур. Демо-данные базы можно сохранить и раскатывать через `adb push` (`run-as`) для каждого языка, чтобы не проходить всё 5 раз.

### 2. Снимки — 8 экранов, каждый на 5 языках (ru, en, tg, uz, tr), светлая тема

1. Главный с карточкой «Урок дня».
2. Урок — «Вспомни» с открытыми аятами и кнопками «Помню» / «Трудно».
3. Итог урока (кольцо, серия, «Завтра: …»).
4. «Мой план» с прогнозом.
5. Ридер: красивый текст, метки «Джуз · Хизб · стр.», док плеера.
6. «Прогресс»: кольцо, активность, джузы.
7. Онбординг: экран «План готов» или слайд «Заучивайте и не забывайте».
8. Тёмная тема — ридер или главный.

Строку состояния сделай чистой: `adb shell cmd statusbar` / demo mode (`settings put global sysui_demo_allowed 1` и широковещательные команды demo — 12:00, полный заряд, Wi-Fi). В конце demo mode выключи.

### 3. Оформление

- Обнови `generate_play_store_assets.py` (или новый скрипт рядом) под 8 экранов и 5 языков.
- Рамка устройства и подпись-заголовок над снимком на языке снимка — короткая польза: «Каждый день — готовый урок», «Повторение в нужный день», «Знаете, когда закончите», «Красивый мусхаф и чтецы», «Честный прогресс», «Работает без интернета» и т. п.
- Шрифты — те, что есть в системе (если SF недоступен для какого-то алфавита — подбери системный с поддержкой таджикской кириллицы ӣ ӯ ҳ ҷ қ ғ и узбекской латиницы `o‘ g‘`).
- Размер 1080×1920 (или 1080×2400 — Play принимает до 2:1; выбери и объясни).
- Feature graphic 1024×500 на 5 языках: обещание + каллиграфия «حفظ», без звёзд.
- Иконку не меняй.

### 4. Описание стора — `play_store_assets/listing/<lang>.md`

- Название ≤ 30 символов.
- Короткое описание ≤ 80.
- Полное ≤ 4000.

Честно, по фактам приложения:
- урок дня (новое → недавнее → старое);
- план и прогноз;
- напоминание, которое не приходит, если урок сделан;
- ридер, 4 чтеца, повтор отрывка, работа с выключенным экраном;
- загрузки для офлайна;
- прогресс и отчёт для устаза;
- перенос в файл;
- приватность: анонимная статистика с выключателем, без рекламы.

Чего нет — не обещай (нет синхронизации в облаке, нет распознавания чтения). Тексты tg/uz/tr пометь для носителя. Добавь раздел «Что нового» для этой версии (≤ 500 символов).

### 5. Манифест

Обнови `play-store-export-manifest.json`: языки, файлы, размеры, источник.
