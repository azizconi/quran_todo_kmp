## Что сделать

### 1. Чтецы

- `Reciter` получает источник:
  - `IslamicNetwork(edition, bitrate)` — как сейчас;
  - `QuranCom(recitationId, pathTemplate)` — файл аята по шаблону из ответа `by_chapter`; шаблон хранить в коде, пример — `Alafasy/mp3/{sss}{aaa}.mp3`.
  
  У каждого чтеца — `recitationId` quran.com для таймингов.
- **Существующие 4 чтеца:** `id`, источник файлов и `cacheKey` **не меняются**, чтобы загрузки людей остались. Если проверка длительностей показала другую запись — файлы этого чтеца переводятся на quran.com с **новым** ключом кэша (старые файлы остаются до LRU), и это записывается в отчёт.
- **Новые 8 чтецов:** ас-Судейс, аш-Шатри, ар-Рифаи, аш-Шурейм, ат-Таблави, Абдуль-Басит (муджаввад), аль-Минышави (муджаввад), аль-Хусари «Для заучивания» (Muallim). Имена на 5 языках в стиле существующих. `id` — стабильные, латиницей.
- **Список чтецов** в «Звуке» и в листе выбора чтеца — группами:
  1. «Для заучивания» — Хусари Muallim, с пояснением «медленно, с паузами для повтора»;
  2. «Чтение (муратталь)»;
  3. «Распевное чтение (муджаввад)».
  
  Прослушивание образца (`ReciterPreview`) работает для всех.
- **Загрузки D3:** размер оценивается для каждого чтеца (битрейты разные). Предупреждение о Wi-Fi и пересчёт размеров работают.

### 2. Тайминги слов

- `WordTimings` на суру и чтеца: `Map<ayahInSurah, List<WordSpan(wordIndex, startMs, endMs)>>`.
  - Загрузка одной суры одним запросом `by_chapter`.
  - Кэш — файл JSON в каталоге кэша (рядом с аудио), ключ `(recitationId, surah)`.
  - В загрузках D3 — вместе с аудио суры, в закреплённом каталоге загрузок.
- Нет сети и кэша → подсветки нет, звук работает как раньше. Ошибок на экран не показываем.
- Неудачный запрос не повторяется чаще раза в 30 с (как `FailureThrottle` переводов).
- Разбор таймингов и сопоставление слов — чистые функции с unit-тестами:
  - Аль-Фатиха;
  - 2:255;
  - аят с Бисмилляхом в 1-м аяте (не 1-я и не 9-я сура);
  - аят, начинавшийся с ۞ (2:26);
  - аят со знаками остановки (ۚ ۖ) отдельными токенами.

### 3. Подсветка по словам

- **Где:**
  - в ридере (`AyahRow`) — у играющего аята;
  - в шаге урока «Послушай»;
  - в доке плеера, если там есть текст аята.
- **Как:**
  - Текущее слово — мягкая подложка цветом акцента (как подсветка аята, но на слово), без мигания. Переход между словами — короткий кроссфейд (≤120 мс).
  - Reduce Motion — без перехода.
  - Скорость воспроизведения ≠ 1 учитывается: позиция берётся у плеера.
- **Позиция:** поток позиции текущего аята (мс) из плеера, опрос не чаще 15–20 раз в секунду и только пока играет и виден экран. Без лишних рекомпозиций всего списка: подсветку рисует только играющий аят.
- **Нажатие на слово:**
  - в ридере во время воспроизведения — перемотка на начало слова;
  - на паузе — воспроизведение аята с этого слова.
  
  Долгое нажатие на аят — лист аята, как сейчас. Нажатие на слово не должно ломать нажатие на аят вне слов.
- **Настройка** в «Aa» (ридер): «Подсветка слов при слушании», по умолчанию вкл.

### 4. Источники

В «Источниках»: аудио и тайминги слов — quran.com / Quran Foundation (recitations, segments), quranicaudio.com. Тексты — 5 языков.
