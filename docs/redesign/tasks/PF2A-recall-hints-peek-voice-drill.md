## Что сделать

### 1. Подсказки в «Вспомни»

**Уровни.** `HifzHintMode` получает уровни:
- `NONE` — аят скрыт целиком;
- `FIRST_WORD` — первое слово видно (уже есть);
- `FIRST_LETTERS` — «Первые буквы»: на месте каждого слова его первая буква;
- `EVERY_OTHER` — «Каждое второе слово»: 1-е, 3-е, 5-е… видны, остальные скрыты;
- `PROGRESSIVE` — «Постепенно скрывать».

**Как работают:**
- **Первая буква слова** — первый символ-буква слова (без огласовок, знаков чтения, татвиля). `ٱ` (алиф васла) показывай как `ا`. Буквы стоят там же, где слова, через пробел, отдельными (изолированными) формами. Цвет — `inkSecondary`. Чистая функция с тестами на реальных аятах: 1:1, 2:255, 112:1, аят с `ۛ`.
- **Скрытое слово** выглядит так же, как скрытый сейчас текст: размытие на Android 12+, полоска ниже. Скрываются только слова; пробелы и строка остаются на месте, чтобы текст не прыгал при открытии.
- **«Постепенно скрывать»** — для одного аята:
  - сначала виден весь;
  - кнопка «Скрыть ещё» скрывает следующую четверть слов с конца: 25 → 50 → 75 → 100 %;
  - на 100 % — обычные «Показать» → «Помню / Трудно»;
  - «Помню / Трудно» доступны на любом шаге: человек может сказать «помню» раньше.
- **Выбор уровня** — чип «Подсказка: …» рядом с кнопками «Вспомни». Нажатие открывает маленький лист с пятью уровнями и одной строкой примера на текущем аяте. Выбор сохраняется в `UiPrefs` (поле то же, значения новые).
- **Перенос B5:** значение уходит в копию по имени. Неизвестное имя при импорте отбрасывается: правило в `BackupSettingsRules`, тест.
- **Ридер и урок.** Подсказки работают одинаково в уроке (новое: фаза «Вспомни»; недавнее и старое) и в «Проверь себя» ридера.
- **Reduce Motion:** скрытие и открытие слова без анимации.

### 2. Подглядывание

- **Нажатие на скрытое слово** текущего аята открывает только его и до конца этого аята в сессии. Тактильный отклик лёгкий. Открытые так слова отмечены тонким подчёркиванием `accent`. Удержание аята (подсмотреть весь аят) остаётся.
- **Счётчик.** В `HifzSession` у каждого аята — число подсмотров. Удержание = подсмотрен весь аят = считается как 2. Кодек сессии — новая версия (`h3`); старая строка `h2` читается без подсмотров. Тест.
- **Предложение «Трудно».** Аят с ≥ 2 подсмотрами:
  - «Трудно» становится основной (залитой) кнопкой, «Помню» — второстепенной;
  - под кнопками строка «Подсмотрено: 2 слова».
  
  Человек выбирает сам. В листе оценки (`RecallGradeSheet`) такие аяты, отмеченные «Помню», **не** становятся трудными сами.
- **Конфликт жестов.** Нажатие на слово не должно открывать лист аята, выбирать строку или листать. Нажатие мимо слов работает как раньше.

### 3. Свой голос

- **Кнопка микрофона** в «Вспомни» (урок и «Проверь себя»): «Записать своё чтение» отрывка.
- **Разрешение `RECORD_AUDIO`** спрашивается по первому нажатию. Отказ — строка «Без микрофона записать не получится» и кнопка «Открыть настройки», если отказ окончательный.
- **Запись:**
  - `MediaRecorder`, AAC в `.m4a`, моно, 64 кбит/с;
  - не дольше 10 минут;
  - перед записью звук чтеца останавливается (`PlaybackController`);
  - на время записи держит фокус аудио;
  - звонок или потеря фокуса останавливают запись и сохраняют сделанное.
- **Хранение:**
  - `context.noBackupFilesDir/recordings/{surah}_{start}_{end}/{epochMillis}.m4a`;
  - последние **20** на отрывок, старше удаляются сами;
  - в копию B5 записи **не** попадают.
- **Лист «Моё чтение»:**
  - список записей отрывка: дата, длительность;
  - ⏯ на каждой; удаление свайпом или в меню, с отменой в снекбаре;
  - «Записать ещё»;
  - «Послушать чтеца» — тот же отрывок через `PlaybackController.playSequence` (повторы урока не нужны: аяты по разу).
- **Своё проигрывание:**
  - отдельный простой плеер (`MediaPlayer` или локальный ExoPlayer), **не** через `PlaybackService`: уведомления нет;
  - перед стартом останавливает чтеца, и наоборот.
- **Во время записи:** крупная кнопка «Стоп», время, уровень громкости — простая полоска, без звёзд и «искр». Reduce Motion — без пульсации.
- **«Загрузки и хранилище»:** строка «Мои записи · N МБ» и «Удалить все записи» с подтверждением.
- **Политика конфиденциальности (en, ru) и экран «Конфиденциальность»:** микрофон используется только по кнопке записи, записи хранятся только на телефоне, не отправляются и не входят в копию; удалить — в листе «Моё чтение» или в «Загрузках».

### 4. Тренировка трудных мест

- **Вход:**
  - «Прогресс»: плитка «Трудных аятов сейчас: N» нажимается при N > 0 → тренировка;
  - итог урока: строка-кнопка «Тренировать трудные · N» при N > 0.
- **Экран `Dest.HardDrill`** (`ui/drill/`):
  - **Очередь:** трудные аяты из `hifz.hardAyahs()` по мусхафу, не больше 20 за раз; осталось больше — в конце «Ещё N в следующий раз».
  - **Карточка трудного аята:** сверху название суры и номер; предыдущий аят суры виден полностью как подсказка-начало (у первого аята суры — без него); сам трудный аят скрыт тем же компонентом «Вспомни» с подсказками и подглядыванием → «Показать» → «Помню / Трудно».
  - **Конец** — итог: «Помню: 7 · Ещё трудные: 3» и кнопка «Готово».
- **Запись — через новое действие репозитория** после каждой суры (группы её трудных аятов):
  ```kotlin
  /** Тренировка трудных (F2a): remembered — счётчик clearsAfter этого аята −1 (0 — отметка снимается), stillHard — снова 2. */
  suspend fun drillHard(surah: Int, remembered: Set<Int>, stillHard: Set<Int>, today: Int = EpochDays.now())
  ```
  - Одна транзакция под тем же `Mutex`, как другие действия.
  - Меняются **только** отметки этих аятов: этапы, сроки, `lastReviewed`, `lapses` не трогаются.
  - Журнал: одна запись `CHECK` на группу. `startAyah`/`endAyah` = min/max тренированных; `passageId` — если один отрывок покрывает всё, иначе null; оценка: нет `stillHard` → `GOOD`, иначе `HARD`.
  - Зеркало пересчитывается для суры, как в `logCheck`.
  - Аят, который уже не трудный или не покрыт, пропускается.
  - Тесты в `commonTest`: счётчик 2 → 1 → снята; `stillHard` ставит 2; лестница и круг не меняются (`lesson(today)` до и после равен, кроме трудных аятов); запись `CHECK` одна.
- **Аналитика без текста:** `drill_completed` (`count_bucket`).
