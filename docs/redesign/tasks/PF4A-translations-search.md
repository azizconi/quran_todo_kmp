## Что сделать

### 1. Каталог и выбор перевода

- **`TranslationCatalog`** в commonMain:
  - список изданий на язык: id ключа, источник (alquran.cloud edition или quran.com id), название и автор на 5 языках интерфейса, письменность;
  - порядок — популярные первыми: ru — Кулиев, Абу Адель, Министерство вакфов; tr — Diyanet, Elmalılı, …; tg — Оятӣ, …; uz — Содиқ (латиница), …; en — Saheeh, Abdel Haleem, …;
  - нынешнее издание каждого языка — по умолчанию, ключ кэша прежний: старый кэш не перекачивается.
- **Выбор:**
  - хранится по языку: у ru свой выбор, у tr свой;
  - смена языка интерфейса берёт выбор этого языка;
  - выбор уходит в копию B5 (поле необязательное).
- **«Aa» → строка «Перевод: Кулиев»** → лист выбора:
  - сначала издания языка интерфейса;
  - ниже свёрнуто «Другие языки» — en и остальные. Перевод на другом языке можно выбрать; язык интерфейса не меняется;
  - отметка «скачан целиком» у скачанных.
- **После выбора** ридер, урок, «Вспомни», мусхаф (где перевод показан) берут новый перевод: всё идёт через тот же репозиторий. Проверь, что у всех мест один источник.
- **Тесты:**
  - каталог: у каждого языка есть издание по умолчанию, ключи уникальны;
  - разбор ответов обоих источников на фикстурах;
  - старый ключ кэша для изданий по умолчанию;
  - смена издания не путает кэш двух изданий одного языка.

### 2. Скачать перевод целиком

- **«Загрузки» → раздел «Переводы»:** выбранный перевод — «Скачать целиком · ≈ N МБ».
  - Размер измерь на 2–3 изданиях и впиши таблицей.
  - Прогресс, отмена, удаление — как у звука и страниц: тот же `DownloadWorker` / `DownloadRunner`, новый вид загрузки.
  - Источник с ответом на суру — 114 запросов. Если у источника есть ответ на весь Коран одним запросом (alquran.cloud `GET /v1/quran/{edition}` — проверь), бери его.
- Скачанный перевод — в Room, как кэш по сурам. Вытеснения у Room-кэша нет; «Удалить» в загрузках удаляет строки издания.
- Без сети — сообщение как у других загрузок.

### 3. Поиск по переводу

- **В поиске вкладки** «Суры» (как сейчас) и «В переводе».
- **«В переводе»:**
  - ищет по выбранному переводу, если он скачан целиком;
  - если не скачан — строка «Чтобы искать по переводу, скачайте его целиком · ≈ N МБ» и кнопка «Скачать»;
  - **без FTS и без смены схемы:** 6236 строк ищутся в памяти. Строки загружаются один раз в фоне и держатся, пока открыт поиск;
  - поиск без учёта регистра и диакритики: ё/е, турецкие İ/ı, таджикские ӣ/ӯ/ҳ/қ/ғ/ҷ — к базовым буквам. Нормализацию — чистой функцией с тестами;
  - от 2 символов, с задержкой ввода ~250 мс;
  - результат: «Аль-Бакара 2:255» и строка перевода с выделенным совпадением, до 200 результатов («Показаны первые 200»);
  - нажатие — `Dest.Reader` на этом аяте (через `openReader`, режим ридера учитывается).
- Пусто — «Ничего не нашлось».
- **Тест:** нормализация на 5 языках, поиск по фикстуре из 20 аятов, порядок результатов (по порядку Корана).

### 4. Тексты и источники

- Все новые строки — на 5 языках (ru, en, tg, uz, tr), с тестом полноты. Таджикский и узбекский — естественно, без кальки. Названия изданий — как приняты на языке.
- «Источники»: каждый источник перевода с автором.
