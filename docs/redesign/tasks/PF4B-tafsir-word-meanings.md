## Проверенные данные (оркестратор, 2026-10-31)

**Тафсиры quran.com** (`GET /api/v4/resources/tafsirs`):
- ru — 170 «Al-Sa'di» (ас-Саади): обычный текст;
- en — 169 «Ibn Kathir (Abridged)»: HTML (`<h2>`, `<p>`), 2:255 — 15 012 символов;
- ar — 16 «Tafsir Muyassar», 91 «Al-Sa'di»;
- на tr, tg, uz тафсиров нет.

**Запросы тафсира:**
- по аяту: `GET /api/v4/tafsirs/{id}/by_ayah/2:255`;
- по суре: `GET /api/v4/tafsirs/{id}/by_chapter/2?per_page=50&page=N`.
- **Проверь:** у ас-Саади толкование бывает общим на группу аятов. Тогда у части аятов текст пустой — покажи толкование группы с пометкой «Толкование аятов 2:1–5». Посмотри, как это видно в ответе (пустой `text`, поле группы).

**Значения слов** (`GET /api/v4/verses/by_chapter/{n}?words=true&word_fields=text_uthmani&per_page=50&page=N`):
- у каждого слова `position`, `char_type_name` (`word` / `end`), `translation.text` (по-английски), `transliteration.text`;
- полный ответ большой (≈240 КБ на 50 аятов). Урежь поля (`fields`, `word_fields`, `translations`) и храни свою компактную копию на суру.

**Слова в нашем тексте.** Наши слова на экране — `displayWords(surah, ayah, text)` (`ui/reader/Bismillah.kt`). Их число совпадает с quran.com везде, кроме 10:1, 13:1 и 50:34. У этих трёх аятов значения слов не показывай.

**Риск по quran.com.** У Quran Foundation с 2026-08-10 новые условия и OAuth для Content API; открытый адрес пока отвечает без ключа. Поэтому:
- источники — за интерфейсами;
- всё скачанное — в кэш на диске;
- запросы — только по нажатию, без предзагрузки всего Корана.

## Что сделать

### 1. Тафсир

- **Лист аята → «Тафсир»** → экран `Dest.Tafsir(surah, ayah, tafsirId?)`. Это полноэкранный текст, не лист: толкования длинные.
- **Экран:**
  - сверху — аят (наш текст, шрифт чтения) и перевод;
  - ниже — толкование;
  - переключатель источника — чипы доступных: «ас-Саади · рус.», «Ибн Касир · англ.», «Муяссар · араб.»;
  - стрелки «Предыдущий / следующий аят» (по суре);
  - HTML Ибн Касира — через `AnnotatedString.fromHtml`: заголовки, абзацы, курсив. Арабские вставки — с направлением справа налево;
  - размер текста — из настроек ридера.
- **Источник по умолчанию по языку:**
  - ru, tg, uz → ас-Саади (рус.);
  - en, tr → Ибн Касир (англ.).
  
  Выбор запоминается (`UiPrefs`) и уходит в копию B5 (поле необязательное). Язык толкования, если он не язык интерфейса, подписан: «Толкование на русском».
- **Данные:**
  - по суре одним разом (страницы `by_chapter`), кэш на диске: `noBackupFilesDir/tafsir_cache/`, вытеснение по общему размеру (как у страниц мусхафа, лимит ~30 МБ);
  - в памяти — последние 3 суры;
  - без сети и без кэша — «Нужен интернет, чтобы загрузить толкование» и «Повторить»;
  - сбои придерживает `FailureThrottle`.
- **Тесты:** разбор ответов (простой текст, HTML, пустой текст у аята в группе), кэш с поддельным источником, выбор источника по умолчанию.

### 2. Значения слов

- **«Aa» → переключатель «Значения слов (англ.)»**, по умолчанию выключен.
- **Когда включён:**
  - нажатие на арабское слово в текстовом ридере показывает подсказку над словом: значение по-английски, транслитерация, номер слова «3 из 7»;
  - слово подсвечено той же подложкой, что у подсветки слов F1a;
  - нажатие вне подсказки закрывает её;
  - нажатие в стороне от слов (поле аята, номер) работает как раньше — выбор аята;
  - long-press — как раньше, лист аята.
- **Когда выключен:** поведение ридера не меняется.
- В уроке, «Вспомни», «Проверке» и на страницах мусхафа — **нет**.
- **Данные:**
  - по суре, при первом нажатии в суре; компактная копия на диске (`noBackupFilesDir/word_meanings/`, вытеснение по размеру);
  - пока грузится — подсказка с индикатором;
  - без сети — «Нужен интернет один раз для этой суры».
- **Сопоставление:** слово экрана `i` (из `displayWords`) ↔ слово quran.com `position = i + 1`, только `char_type_name == word`. У 10:1, 13:1, 50:34 и у любого аята, где число слов не совпало, подсказка говорит «Для этого аята значения слов недоступны».
- **Вместе с таджвидом и подсветкой слов F1a:** нажатие работает поверх цветов; во время слушания тоже.
- **Тесты:** разбор и компактная копия, сопоставление слов (фикстура суры 1 и 2:1–10, три особых аята), хранилище с поддельным источником.

### 3. Тексты и источники

- Все новые строки — на 5 языках (ru, en, tg, uz, tr), с тестом полноты. Таджикский и узбекский — естественно, без кальки.
- «Источники»:
  - «Тафсир: ас-Саади, Ибн Касир (сокр.), ат-Тафсир аль-Муяссар — quran.com»;
  - «Значения слов: quran.com (по-английски)».
