## Как поставить release на эмулятор, не потеряв данные

На эмуляторе стоит debug-сборка с данными владельца-тестера: «знает Джуз Амму», план, журнал. **Данные не терять.**

1. Пока стоит debug, сохрани данные: `adb shell run-as tj.app.quran_todo tar -cf - databases shared_prefs files no_backup > backup.tar`. Проверь размер файла.
2. Подпиши release-APK **debug-ключом** — тем же, что у debug-сборки. Тогда release ставится поверх с данными:
   - `zipalign -p -f 4 in.apk aligned.apk`;
   - `apksigner sign --ks ~/.android/debug.keystore --ks-pass pass:android --key-pass pass:android --ks-key-alias androiddebugkey --out signed.apk aligned.apk`.
   
   Это публичный стандартный пароль debug-ключа Android, не секрет. Инструменты лежат в `~/Library/Android/sdk/build-tools/<версия>/`.
3. `adb install -r signed.apk`.
4. После проверки поставь обратно последнюю debug-сборку `-r` поверх. Если данные пропали — восстанови из `backup.tar` (через `run-as`, после `force-stop`).

- `./gradlew :composeApp:assembleRelease`.
- Запиши размер APK и сравни с прежним AAB `~/quran_hifz_release_backup/composeApp-release.aab` (сравнение примерное).
